# M10 · Mantener la base: números y álgebra  🟢

**Tus datos:** aquí vas muy bien — NUM-por 4/4, NUM-pot 3/3, NUM-real 2/2, ALG-ecu 3/3, ALG-func 2/2. Son ≈ 25 % de las preguntas puntuables: **no los descuides**, pero tampoco gastes tiempo: 1 set corto cada 2–3 días.

## Checklist (si lo dominas, sigue con otra cosa)
- [ ] Potencias: aᵐ·aⁿ, (aᵐ)ⁿ, a⁻ⁿ, raíces como exponentes fraccionarios, notación científica.
- [ ] Porcentajes sucesivos se **multiplican**; "p % de q" vs "q es el p % de …".
- [ ] Intervalos y desigualdades: al multiplicar/dividir por negativo, **se invierte el signo**.
- [ ] Números reales: racional + irracional = irracional; racional·irracional (≠0) = irracional.
- [ ] Productos notables y factorización (cuadrado de binomio, suma por diferencia).
- [ ] Funciones por tramos, potencia y raíz: ¿cómo cambia f si x se duplica?
- [ ] Trigonometría en funciones: amplitud, período, desfase (aparece en 1–2 preguntas).

## Práctica rápida
```bash
python3 paes.py practicar NUM-por -n 4
python3 paes.py practicar ALG-ecu -n 4
python3 paes.py gemelas NUM-pot     # preguntas oficiales para chequearte
```
